# خط ثمانية — ضع الملفات هنا

ملفات الخط **ليست في المستودع**: ترخيص ثمانية يسمح بالاستخدام الشخصي والتجاري مجانًا، لكنه يمنع إعادة توزيع الملفات أو استضافتها للتنزيل.

**طريقتان:**
1. إن كان الخط مثبتًا على ويندوز، شغّل `setup\setup.ps1` وسينسخ الملفات إلى هنا تلقائيًا.
2. نزّله من الصفحة الرسمية: <https://ask.thmanyah.com/hc/en-001/articles/45993930027281-Thmanyah-Font-for-Everyone> (يصل بالبريد)، ثم ضع ملفات `.otf` هنا بأسمائها الأصلية.

**الملفات التي يحتاجها الخط (إلزامي):** `thmanyahsans12_medium.otf` · `thmanyahsans12_bold.otf` · `thmanyahsans12_black.otf`
باقي الأوزان (Serif Display/Text، Light، Regular) اختيارية للتصاميم الجديدة.
